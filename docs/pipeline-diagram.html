Feature Extraction + Phase Segmentation
feature_engine.py - 274 lines
NumPy / SciPy
Function
extract_features( landmarks: np.ndarray (N, 33, 3), fps: float, stroke_type: str, handedness: str = "right" ) -> FeatureExtractionResult
Key Logic
1. Resolve hitting arm by handedness 2. Compute 6 joint angles per frame 3. Savitzky-Golay smoothed velocities 4. Phase detection via wrist x-velocity sign changes + peak wrist speed 5. Contact frame = argmax(wrist_speed)
Output: FeatureExtractionResult
joint_angles: dict[str, np.ndarray] # degrees, shape (N,) each keys: elbow_angle, shoulder_rotation, hip_rotation, trunk_rotation, knee_bend, racket_arm_elevation velocities: dict[str, np.ndarray] # smoothed speed, shape (N,) each keys: wrist_speed, elbow_speed, hip_speed phases: dict[str, tuple[int, int]] # (start_frame, end_frame) inclusive keys: preparation, backswing, forward_swing, contact, follow_through contact_frame: int # frame index of peak wrist speed
user_features: FeatureExtractionResult pro_reference: dict (from ProReferenceDB, keys: joint_angles, phases) fps: float

DTW Comparison
dtw_comparator.py - 241 lines
tslearn
Function
compare_swing( user_features: FeatureExtractionResult, pro_reference: dict, fps: float = 30.0 ) -> ComparisonResult
Key Logic
1. Resample segments to equal length 2. Per-joint, per-phase DTW distance 3. Score = 100 * exp(-dist / 50) 4. Weighted overall: forward_swing 35%, contact 30%, backswing 15%, follow_through 15%, preparation 5% 5. Classify severity: <40 critical, <60 moderate, <70 minor
Output: ComparisonResult
overall_score: float # 0-100 (higher = more like pro) phase_scores: dict[str, float] # per-phase 0-100 keys: preparation, backswing, forward_swing, contact, follow_through deviations: list[Deviation] # sorted worst-first Deviation: joint: str # e.g. "elbow_angle" phase: str # e.g. "forward_swing" mean_diff_degrees: float # signed difference max_diff_degrees: float # absolute max difference timing_offset_ms: float # +ahead / -behind pro severity: str # "critical" | "moderate" | "minor" description: str # human-readable
comparison: ComparisonResult stroke_type: str, pro_reference_name: str
