2. Analysis Pipeline
Backend worker processes the video through 6 stages asynchronously
Confirm Upload
POST /api/{id}/confirm
React
After S3 upload succeeds, frontend calls confirm endpoint which enqueues the RQ job.
enqueue job
Redis Queue
process_analysis(id)
RQ
Job queued in Redis. Single worker picks it up. Frontend polls GET /api/analysis/{id} every 2s for status updates.
dequeue
Worker Process
Runs full pipeline
RQ Worker
Single worker process runs all 6 pipeline stages sequentially. Updates Analysis status after each stage.
A
Frame Extraction
FFmpeg: video to PNGs at 30fps
FFmpeg
ffprobe detects FPS/duration, then ffmpeg extracts frames. Auto-downsamples >60fps to 30fps. Max 30s duration enforced.
B
Pose Estimation
33 landmarks per frame (x, y, z)
MediaPipe
BlazePose heavy model detects 33 body landmarks per frame. Linear interpolation fills gaps. Fails if detection rate <50%.
C
Racquet Detection
YOLOv8 bounding boxes (non-fatal)
Ultralytics
Optional stage. YOLOv8 detects tennis racquet position per frame. If it fails, pipeline continues without racquet data.
D
Feature Extraction
Joint angles, velocities, phase segmentation
NumPy / SciPy
Computes 6 joint angles + 3 velocities per frame. Segments swing into 5 phases using wrist velocity sign changes.
E
DTW Comparison
Phase-segmented matching vs pro
tslearn
Each phase compared independently against pro reference via Dynamic Time Warping. Produces per-phase scores (0-100) and deviation list.
F
Coaching Feedback
Structured deviation data to drills
Claude Sonnet
Claude API receives scores + deviations, returns structured JSON: summary, priority fixes, positive notes, and progressive drill plan.
